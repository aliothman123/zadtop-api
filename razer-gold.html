Razer Gold check

Razer Gold redeem puts the PIN on your own wallet. Razer Gold checker only reads the PIN. Checking does not spend it. Both cost 5 requests for each PIN that gets a verdict.

Open @ZadTopBot API reference

Razer Gold checker

The checker answers live, used, or invalid. There is no player ID and no pack. The PIN is not spent. Use game=razer.

curl -sS -X POST https://api.zadtop.com/v1/codes/check \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"game":"razer","codes":["YOURPIN"]}'

شحن ريزر جولد

شحن ريزر يضع الرصيد في محفظتك أنت. أرسل البريد وكلمة السر مع الأكواد. كلمة السر تُستخدم لتسجيل الدخول ولا تُحفظ. المحفظة المغلقة، أو التي لم تُفعَّل بعد، أو الممتلئة تُرفض قبل إرسال أي كود، ولا يُخصم شيء في هذه الحالات. الحقل game=razer_recharge. كل كود صدرت له نتيجة يكلف 5 طلبات.

فحص كود ريزر

ريزر تشيكر وفحص كود ريزر هما القراءة فقط: صالح، أو مستخدم، أو خاطئ. الكود لا يُستهلك. خمسة طلبات لكل كود.

curl -sS -X POST https://api.zadtop.com/v1/codes/check \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"game":"razer_recharge","email":"name@mail.com","password":"secret","codes":["YOURPIN"]}'
