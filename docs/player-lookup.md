# Player ID lookup

Player lookup returns the in-game name and region before any code is spent. It works for the games that redeem to a player ID.

Bot: [@ZadTopBot](https://t.me/ZadTopBot) · API: https://api.zadtop.com · Page: https://aliothman123.github.io/zadtop-api/player-lookup.html

Independent service. Not affiliated with Garena, Krafton, Tencent, Yalla Games, Apple, Razer, or Jawaker.

## Player lookup

GET /v1/player/lookup?game=freefire&player_id=2186053213 returns the name and region. Cost 0.25. It does not spend a code.
