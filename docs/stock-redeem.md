# Stock redeem

Stock redeem uses codes you already saved in the bot. You pick the game and the pack instead of pasting cards into each order.

Bot: [@ZadTopBot](https://t.me/ZadTopBot) · API: https://api.zadtop.com · Page: https://aliothman123.github.io/zadtop-api/stock-redeem.html

Independent service. Not affiliated with Garena, Krafton, Tencent, Yalla Games, Apple, Razer, or Jawaker.

## Stock

Save codes by game and pack, then POST /v1/jobs/stock-redeem. GET /v1/stock/summary lists what you hold. POST /v1/order/screenshot returns the shop confirmation image.
