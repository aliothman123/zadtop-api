# FAQ

## Is this the official game API?

No. Zad Top is independent. It is not Garena, Krafton, Tencent, Yalla, Apple, Razer, or Jawaker.

## Do I need a subscription?

A new account gets 10 free redeems, once, for every game. After that, pick a daily plan. You can add a game later and pay the difference for the days left.

## How do I know a code is already used?

Use Check codes in the bot, or `POST /v1/codes/check`. A good card stays good. Reading a normal card costs one request, the same as redeeming it. A Razer Gold PIN costs five, and only when you are checking or recharging Razer.

## What if a redeem fails?

Each code is reported on its own. A refusal from the shop — used, invalid, wrong region — is a real answer and stays charged. If the connection dropped, the shop refused the request, or no result came back, that request is returned.

## Which countries work?

Almost every country. Free Fire lookup names the United States, Argentina, Chile and Russia when Garena sells no vouchers there, before a code is sent.

## Is the Razer password saved?

No. It is used to sign in and is not stored.

## Can I check a Ludo Gold code?

No. Gold has no check. Do not send a Gold code to the Diamonds check: it can be spent.
