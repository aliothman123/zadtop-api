iTunes check

An iTunes check reads the dollar balance of an Apple Gift Card. It does not redeem the card. The same check is what people call an iTunes checker, an Apple checker, ايتونز تشيكر, and ابل تشيكر.

Open @ZadTopBot API reference

Apple checker

Apple checker and iTunes gift card checker are the same read. A live card comes back valid with its balance. Apple does not separate an invalid card from one already redeemed, so both read as invalid. There is no player ID and no pack. game=itunes. One request per card.

The first read after a quiet spell can take up to a minute. Later reads in the same run are faster.

ايتونز تشيكر

ايتونز تشيكر وآيتونز تشيكر يقرآن رصيد بطاقة آبل بالدولار دون شحنها. فحص بطاقة ايتونز وفحص بطاقة آبل هما الخدمة نفسها.

ابل تشيكر

ابل تشيكر وآبل تشيكر هما اسمان آخران لفحص بطاقة الهدايا من آبل. البطاقة السارية ترجع برصيدها. البطاقة غير الصالحة والبطاقة المستخدمة سابقاً كلتاهما تظهر غير صالحة، لأن آبل لا تفصل بينهما.

curl -sS -X POST https://api.zadtop.com/v1/codes/check \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"game":"itunes","codes":["X000000000000000"]}'
