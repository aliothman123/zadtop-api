Open @ZadTopBot API reference

شحن جواكر

شحن جواكر يرسل فئات التوكنز من 4250 إلى 825000 على رقم اللاعب. لا يوجد فحص مستقل للكود. الرمز المكوّن من 12 خانة لا يُفحص، والكود لا يُرسل مرة ثانية إذا ضاعت الإجابة. الحقل game=jawaker.

curl -sS -X POST https://api.zadtop.com/v1/jobs/instant-redeem \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"player_id":"123456","codes":["YOURCODE"],"game":"jawaker"}'
