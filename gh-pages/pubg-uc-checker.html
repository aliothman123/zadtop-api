PUBG check

A PUBG UC checker reads the voucher without redeeming it. A good card stays good. Arabic searches for the same tool use فحص كود ببجي.

Open @ZadTopBot API reference

فحص كود ببجي

فحص كود ببجي يخبرك إن كان الكود غير مستخدم أو مستخدماً أو منتهي الصلاحية أو غير صالح. إن كان المتجر يعرف القيمة أو اللاعب أو وقت الاستخدام يعيدهما. الفحص لا يشحن الكود، ويكلف طلباً واحداً لكل بطاقة.

curl -sS -X POST https://api.zadtop.com/v1/codes/check \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"game":"pubg","with_value":true,"codes":["YOURCODE"]}'

A card you still want to spend goes to PUBG UC redeem.
