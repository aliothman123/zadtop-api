Recipes

Every call uses X-API-Key. Replace the sample player IDs and codes. The full field list is in the reference.

Redeem Free Fire

curl -sS -X POST https://api.zadtop.com/v1/jobs/instant-redeem \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"player_id":"2186053213","codes":["4233939008625064"],"game":"freefire"}'

Check PUBG cards

curl -sS -X POST https://api.zadtop.com/v1/codes/check \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"game":"pubg","with_value":true,"codes":["YOURCODE"]}'

Look up a player

curl -sS "https://api.zadtop.com/v1/player/lookup?game=freefire&player_id=2186053213" \
  -H "X-API-Key: pk_YOUR_KEY"

Razer Gold recharge

The password signs the wallet in and is not stored. Five requests for each PIN that got a verdict.

curl -sS -X POST https://api.zadtop.com/v1/codes/check \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"game":"razer_recharge","email":"name@mail.com","password":"secret","codes":["YOURPIN"]}'

Wait for the job

curl -sS "https://api.zadtop.com/v1/jobs/JOB_ID?wait=25" \
  -H "X-API-Key: pk_YOUR_KEY"

What a failed card can say

err_codeMeaning
CODE_ALREADY_USEDAlready redeemed. Do not retry it.
INVALID_CODEThe shop does not recognise the card.
REGION_MISMATCHWrong region for this player.
PLAYER_NOT_FOUNDNo account with this ID. The cards were not used.
NETWORKThe connection dropped, the shop refused the request, or no result came back. Refunded. Retry.
VERIFICATION · VERIFICATION_FAILEDVerification did not pass. The card was not spent. Retry later.

A shop refusal is an answer and stays charged. A failure before a result is returned to your allowance.
