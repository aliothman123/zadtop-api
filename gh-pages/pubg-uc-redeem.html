PUBG UC redeem

PUBG UC redeem credits Unknown Cash codes to a player ID. The same route covers Free Fire and the other games: only the game field changes.

شحن شدات ببجي

شحن شدات ببجي يتم برقم اللاعب. الفئات من 60 إلى 8100 شدة. كل كود يكلف طلباً واحداً، ونتيجة كل كود تظهر وحدها. في الواجهة الحقل هو game=pubg.

Packs and the request

Packs run from 60 UC up to 8,100 UC. Look up the in-game name first if you want to confirm the account, then redeem. A wrong player ID is reported before the cards are spent when the shop says the account does not exist.

curl -sS -X POST https://api.zadtop.com/v1/jobs/instant-redeem \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"player_id":"5123456789","codes":["YOURCODE"],"game":"pubg"}'
