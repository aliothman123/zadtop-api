What a Free Fire redeem includes

Packs are 100, 210, 530, 1,080 and 2,200 diamonds. One redeem costs one request per code. A new account starts with 10 free redeems. Plans run from 25 to 10,000 redeems a day, priced from 5 USDT for one game.

You can redeem codes you paste, or redeem a pack you already stored in the bot. After a successful order you can download the shop confirmation image.

curl -sS -X POST https://api.zadtop.com/v1/jobs/instant-redeem \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"player_id":"2186053213","codes":["4233939008625064"],"game":"freefire"}'

The call returns a job. Read it with GET /v1/jobs/{id} or add ?wait=25. A finished job still lists each code on its own, with success and err_code.
