Free Fire check

A Free Fire checker reads the card and leaves it unused when it is still good. People also search this as فري فاير تشيكر and فحص كود فري فاير.

Open @ZadTopBot API reference

فري فاير تشيكر

فري فاير تشيكر يقرأ الكود قبل الشحن. النتيجة: غير مستخدم، أو مستخدم، أو غير صالح، ومعها فئة الماسات إن كان الكود سليماً. الفحص لا يستهلك الكود. فحص كود فري فاير يكلف طلباً واحداً لكل بطاقة.

What the checker returns

Send up to 20 cards on POST /v1/codes/check, or up to 10,000 as a job on POST /v1/jobs/code-check. Use game=freefire. A Code checking subscription can call the check routes on its own: 150,000 checks for 100 USDT, or 250,000 for 150 USDT.

curl -sS -X POST https://api.zadtop.com/v1/codes/check \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"game":"freefire","codes":["4233939008625064"]}'

When you are ready to spend a good card, use Free Fire redeem.
