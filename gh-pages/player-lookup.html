Player ID lookup

Player lookup returns the in-game name and region before any code is spent. It works for the games that redeem to a player ID.

Open @ZadTopBot API reference

فحص آيدي قبل الشحن

معرفة اسم اللاعب تتم قبل صرف أي كود. التكلفة 0.25 طلب. المسار GET /v1/player/lookup مع game وplayer_id.

curl -sS "https://api.zadtop.com/v1/player/lookup?game=freefire&player_id=2186053213" \
  -H "X-API-Key: pk_YOUR_KEY"
