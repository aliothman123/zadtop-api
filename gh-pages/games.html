Every game on one plan.

Change the game field. The routes stay the same. A plan can cover one game, two, or all of them.

Free Fire

Redeem Garena vouchers onto a player ID. Packs: 100, 210, 530, 1,080 and 2,200 diamonds. Check a card first: unused, used, or invalid, with the pack it is worth. game=freefire.

PUBG Mobile

Redeem UC by player ID. Packs from 60 to 8,100 UC. A check can also return the value, when the card was used, and the player, when the shop knows them. game=pubg.

Yalla Ludo

Diamonds and Gold, from $2 to $500. After the player ID you choose the pack. Diamonds codes can be checked: unused, used, or invalid. Gold has no check. Never send a Gold code to the Diamonds check — it can be spent. Use game=ludo or game=ludogold with tier.

Jawaker

Token packs from 4,250 to 825,000, redeemed by player number. There is no standalone code check. A 12-character pin cannot be checked, and a code is not sent a second time if the answer is lost. game=jawaker.

iTunes

Read an Apple Gift Card balance in dollars without redeeming it. A live card comes back valid with its balance. Apple does not separate an invalid card from one already redeemed, so both read as invalid. Check only: no player, no packs. The first read after a quiet spell can take up to a minute. game=itunes.

Razer Gold check

Find out whether a PIN is live, used, or invalid. The PIN is not spent by checking. No player ID and no pack. Each read costs 5 requests. game=razer.

Razer Gold recharge

Credit PINs to your own wallet. Send the email and password with the codes. The password is used to sign in and is not saved. A closed wallet, a wallet that is not activated yet, or a full wallet is refused before a PIN is sent. A credited PIN comes back recharged, with the amount when Razer reports it. Each PIN that got a verdict costs 5 requests. game=razer_recharge.

Prices, packs and examples also live on zadtop.com/games and in the API reference.
