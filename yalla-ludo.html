Yalla Ludo API

Yalla Ludo redeem covers Diamonds and Gold. After the player ID you choose the pack. Diamonds codes can be checked. Gold codes cannot.

Open @ZadTopBot API reference

شحن يلا لودو

شحن يلا لودو وشحن لودو يشمل الماس والذهب، من 2 إلى 500 دولاراً. بعد آيدي اللاعب تختار الفئة. الماس يُفحص: غير مستخدم أو مستخدم أو غير صالح. الذهب بلا فحص.

لا ترسل كود ذهب إلى فحص الماس. قد يُستهلك. للشحن استخدم game=ludo أو game=ludogold مع tier.

curl -sS -X POST https://api.zadtop.com/v1/jobs/instant-redeem \
  -H "X-API-Key: pk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"game":"ludo","player_id":"12345678","tier":2,"codes":["YOURCODE"]}'
