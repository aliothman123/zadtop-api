# زاد ٹاپ API — فری فائر، پبجی، یالا لوڈو، جواکر، آئی ٹیونز، ریزر گولڈ

آزاد ٹیلیگرام بوٹ [@ZadTopBot](https://t.me/ZadTopBot) اور HTTP API: `https://api.zadtop.com`۔

کوڈ ریڈیم، کوڈ چیک، پلیئر کا نام، اور اپنا اسٹاک۔ گارینا، کرافٹون، یالا، ایپل، ریزر یا جواکر سے وابستہ نہیں۔

[English](./README.md) · [دستاویزات](https://api.zadtop.com/docs) · [سائٹ](https://www.zadtop.com/)

ہیڈر `X-API-Key`۔ فعال پلان اور API ایڈ آن (۱۵ ڈالر / ۳۰ دن)۔

ریزر گولڈ پن چیک پن خرچ نہیں کرتا، فی پن ۵ ریکویسٹ۔ اپنے والیٹ میں چارج پر پاس ورڈ محفوظ نہیں ہوتا۔ لوڈو گولڈ کوڈ ڈائمنڈ چیک پر نہ بھیجیں؛ خرچ ہو سکتا ہے۔

تلاش: فری فائر ریڈیم بوٹ، پبجی UC API، یالا لوڈو ڈائمنڈ، جواکر ٹوکن، آئی ٹیونز بیلنس، ریزر گولڈ پن، ZadTopBot۔
