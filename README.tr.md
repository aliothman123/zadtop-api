# Zad Top API — Free Fire, PUBG, Yalla Ludo, Jawaker, iTunes, Razer Gold

Bağımsız Telegram botu [@ZadTopBot](https://t.me/ZadTopBot) ve HTTP API: `https://api.zadtop.com`.

Kod yükleme, kod kontrolü, oyuncu adı ve stok. Garena, Krafton, Yalla, Apple, Razer veya Jawaker ile bağlantılı değildir.

[English](./README.md) · [Belgeler](https://api.zadtop.com/docs) · [Site](https://www.zadtop.com/) · [Sayfalar](https://aliothman123.github.io/zadtop-api/)

`X-API-Key` başlığı gerekir. Aktif plan + HTTP API eklentisi (30 gün / 15 USDT).

| `game` | |
| --- | --- |
| `freefire` | elmas yükleme ve kart kontrolü |
| `pubg` | UC yükleme ve kontrol |
| `ludo` / `ludogold` | elmas ve altın. Altın kodunu elmas kontrolüne göndermeyin |
| `jawaker` | jeton. Ayrı kontrol yok |
| `itunes` | bakiye okuma, yükleme yok |
| `razer` | PIN kontrolü, PIN harcanmaz, PIN başına 5 istek |
| `razer_recharge` | PIN kendi cüzdanınıza. Şifre saklanmaz. Sonuç alan PIN başına 5 istek |

Arama: Free Fire kod yükleme, PUBG UC API, Yalla Ludo elmas, Jawaker jeton, iTunes bakiye, Razer Gold PIN, ZadTopBot.
