Free Fire API, PUBG API, and iTunes check

Zad Top is the Telegram bot @ZadTopBot and the HTTP API at api.zadtop.com. Use the Free Fire API and the PUBG API to redeem codes, run an iTunes check on an Apple gift card, and use the Razer Gold checker, the Yalla Ludo API, and the Jawaker API from the same key.

What you can build

Instant redeem

Send a player ID and codes. The bot confirms the in-game name first, then reports every code on its own line.

Code check

Read a card without redeeming it: unused, used, or invalid. A good card stays good.

Your stock

Keep codes in the bot by pack, then redeem by choosing a pack instead of pasting codes.

Shop receipts

A successful redeem can be returned as the shop’s order confirmation image.

Three steps

1. Get a key

In @ZadTopBot, hold an active plan and the HTTP API add-on (15 USDT / 30 days). Create a key. A new key replaces the previous one.

2. Send a job

POST /v1/jobs/instant-redeem with X-API-Key. You receive a job_id immediately.

3. Read the result

GET /v1/jobs/{id}, or add ?wait=25. A job marked done means the work finished. Each code has its own success and err_code.
