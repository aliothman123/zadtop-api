# رابط زاد تاپ — فری‌فایر، پابجی، یلا لودو، جواکر، آیتونز، ریزر گلد

ربات تلگرام [@ZadTopBot](https://t.me/ZadTopBot) و API به نشانی `https://api.zadtop.com`.

شارژ کد، بررسی کد، نام بازیکن و موجودی شما. وابسته به گارنا، کرافتون، یلا، اپل، ریزر یا جواکر نیست.

[English](./README.md) · [مستندات](https://api.zadtop.com/docs) · [سایت](https://www.zadtop.com/)

کلید در سربرگ `X-API-Key`. طرح فعال به‌علاوهٔ افزونهٔ API (۱۵ دلار / ۳۰ روز).

بررسی پین ریزر گلد کد را مصرف نمی‌کند و هر پین ۵ درخواست است. شارژ به کیف خودتان رمز را ذخیره نمی‌کند. کد طلای لودو را به بررسی الماس نفرستید؛ ممکن است مصرف شود.

جستجو: ربات شارژ فری فایر، API شدات پابجی، الماس یلا لودو، توکن جواکر، موجودی آیتونز، پین ریزر گلد، ZadTopBot.
